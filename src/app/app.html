🧠 TIWIKOM FD

Things I Wish I Knew On My First Day

A web platform designed to help companies improve onboarding. Senior employees share insights and tips, while newcomers can read, react, and comment — making every first day easier.

⚙️ Tech Stack

  • Frontend: Angular (TypeScript)
  • Backend: .NET 8 (C# API)
  • Database: SQL Server / PostgreSQL via EF Core
  • Auth: Role-based (Admin, Senior, Intern)

🚧 Current Status

Frontend under development — using mock data and placeholder routes.
